## 🧠 Enfoque de trabajo

Mi forma de trabajar se apoya en cuatro principios:

- **Integraciones trazables antes que rápidas**  
  Prefiero flujos claros, monitoreables y auditables a soluciones opacas difíciles de sostener.

- **Datos reutilizables antes que reportes aislados**  
  Diseño estructuras pensadas para escalar análisis, controles y reportería regulatoria, no solo para resolver una consulta puntual.

- **Controles continuos y automatizados**  
  Implemento reglas de monitoreo, alertas tempranas y flujos de datos resilientes para garantizar cumplimiento sin fricción operativa.

- **Infraestructura simple antes que compleja**  
  Automatizo y estandarizo solo lo necesario. La complejidad innecesaria siempre se paga después.
